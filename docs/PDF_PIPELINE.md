# مسیر تولید PDF

1. WordPress گزارش ذخیره‌شده و اطلاعات نمایشی پت را با `request_id` به Python می‌فرستد.
2. Python داده را validate می‌کند و renderer راست‌به‌چپ را اجرا می‌کند.
3. پاسخ باید bytes واقعی با header `Content-Type: application/pdf` باشد.
4. WordPress hash فایل را ذخیره می‌کند و فایل را با download کنترل‌شده به کاربر می‌دهد.

PDF باید شامل پروفایل پت، رژیم فعلی، تحلیل تغذیه‌ای و بخش مستقل «هشدارهای تغذیه‌ای و سلامتی» باشد. هشدار نباید داخل جدول رژیم ادغام شود.
