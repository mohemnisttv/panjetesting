# وضعیت بسته آزمایشی

این خروجی بسته قابل نصب برای بررسی در محیط آزمایشی است؛ تکمیل همه فازهای محصول یا آمادگی انتشار عمومی تأیید نشده است.

## اصلاحات این مرحله

- فایل‌های src داخل ZIP افزونه قرار گرفته‌اند و autoloader مسیر نصب را پشتیبانی می‌کند.
- پیشوند PSR-4 و حداقل PHP 8.3 اصلاح شده‌اند.
- صفحه‌بندی گزارش‌ها با LIMIT/OFFSET اجرا می‌شود و نام پت در پاسخ حفظ شده است.
- خطای احراز هویت نمونه Python اصلاح شد؛ کلید پیش‌فرض حذف شده است.
- تحلیل، تولید رژیم و PDF تا اتصال موتور واقعی با خطای 501 پاسخ می‌دهند؛ نتیجه ساختگی تولید نمی‌شود.

## بررسی انجام‌شده

ساخت ZIP، صحت CRC بسته افزونه، وجود فایل‌های ضروری و syntax پایتون بررسی شدند. PHP CLI، WordPress آزمایشی و وابستگی‌های FastAPI در محیط موجود نبودند؛ فعال‌سازی واقعی، اتصال API و بررسی بصری اجرا نشده‌اند.

## کارهای باقی‌مانده

- تطبیق دقیق پرسشنامه و payload با prototype و قرارداد واقعی افزونه.
- بازطراحی کامل رابط کاربر و مدیر؛ CSSهای قبلی به‌تنهایی این فازها را کامل نمی‌کنند.
- تولید PDF معتبر با فونت و RTL و دانلود محافظت‌شده.
- حذف وابستگی خواندن غذا از جدول panje_food_database به نفع CSV، همراه با حفظ داده و تاریخچه نسخه‌ها.
- بررسی و ترمیم کنترل‌شده رشته‌های فارسی آسیب‌دیده.
- محدودسازی واقعی بدنه در reverse proxy: کنترل Content-Length در نمونه، درخواست بدون این هدر را محدود نمی‌کند.
- ذخیره واقعی idempotency و آزمون‌های همزمانی، امنیت و بازپرداخت.

## نصب

از اطلاعات سایت آزمایشی نسخه پشتیبان بگیرید. در افزونه‌ها > افزودن > بارگذاری افزونه، فایل `dist/panje-install.zip` را انتخاب کنید. PHP باید 8.3 یا بالاتر باشد. بسته سرور جداست و داخل WordPress نصب نمی‌شود. راهنمای `python/README.md` و اسناد سرور در بسته دوم موجودند.
