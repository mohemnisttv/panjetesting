# گزارش فاز ۱ — ممیزی و تثبیت

## دامنه

این سند baseline فعلی افزونه Panje و قرارداد نمونه ارتباط با موتور Python را ثبت می‌کند. منطق پرسشنامه، قوانین و محاسبات در این فاز تغییر نمی‌کند.

## وضعیت فعلی

- WordPress مسئول رابط کاربری، REST، ذخیره درخواست/گزارش، کیف پول و PDF است.
- Python باید مسئول محاسبات، قوانین، نیازهای مواد مغذی، هشدارها و توصیه‌ها بماند.
- دیتابیس غذا همچنان CSV و versioned است.
- پردازش‌های سنگین باید از مسیر صف انجام شوند.

## ریسک‌های ثبت‌شده

1. کلاس‌های فعلی global و static هستند و namespace/autoloading ندارند.
2. قرارداد JSON بین WordPress و Python به‌صورت schema رسمی ثبت نشده است.
3. برخی رشته‌های فارسی در فایل‌های فعلی دچار خرابی encoding هستند.
4. REST به rate limit، محدودیت payload و schema validation مرکزی نیاز دارد.
5. فایل PDF با URL مستقیم uploads ارائه می‌شود و باید در فاز PDF به download کنترل‌شده تبدیل شود.
6. import CSV باید اعتبارسنجی محتوایی و پردازش batch داشته باشد.

## معیار خروج فاز ۱

- baseline معماری ثبت شده است.
- نمونه FastAPI قابل اجرا و مستقل در `python/fastapi_server_example.py` قرار دارد.
- endpointها قرارداد خطا، احراز هویت، idempotency و versioning مشخص دارند.
- هیچ سؤال، قانون یا محاسبه موجود تغییر نکرده است.
